# Lifestyle Home Spaces Assets

This directory contains all the static assets (images, icons, logos) for the Lifestyle Home Spaces website.

## Required Assets
The following files should be added to their respective directories. If an asset is missing, the website will use a sophisticated neutral placeholder.

- **brand/lifestyle-logo.svg**: The official Lifestyle Home Spaces logo used in the navbar and footer.
- **building/building-hero.jpg**: Large architectural photograph of the Lifestyle Home Spaces building used in the hero section.
- **building/building-exterior.jpg**: Exterior shot of the building used in the "Building Showcase" section.
- **interiors/living-room.jpg**: High-quality interior shot of the living room.
- **interiors/kitchen.jpg**: High-quality interior shot of the kitchen.
- **interiors/bedroom.jpg**: High-quality interior shot of the bedroom.
- **interiors/balcony.jpg**: High-quality interior shot of the balcony.
- **interiors/bathroom.jpg**: High-quality interior shot of the bathroom.
- **floor-plans/2bhk.jpg**: Architectural line-art floor plan for the 2 BHK flat.
- **floor-plans/3bhk.jpg**: Architectural line-art floor plan for the 3 BHK flat.

## Additional Images
- **gallery/**: Add any additional images (building exterior, entrance, amenities, surroundings) here for the cinematic masonry gallery.

## Notes
- Do NOT use random unrelated buildings or fictional interiors.
- All building images must be of the actual Lifestyle Home Spaces property.
- Images should be optimized for web (e.g., compressed JPEG or WebP) to maintain high performance.
